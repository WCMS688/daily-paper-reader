## 摘要
亚时钟周期时间分辨率下的功耗估计对于电源分配网络（PDN）设计、动态电压跌落分析以及硅前功耗侧信道安全评估等任务至关重要。设计人员通常依赖商业化的布局后门级功耗分析工具来完成这些任务，但这些流程计算成本高昂，且随设计规模和负载长度的扩展性较差。基于机器学习（ML）的功耗估计框架在加速功耗估计方面展现出前景，但先前的工作仅涉及平均功耗或每周期功耗估计。我们提出了PowerScope，这是首个基于ML的周期内功耗估计框架。PowerScope在推理时仅基于RTL仿真轨迹运行，无需针对每个负载进行布局后门级仿真和功耗分析。在多样化的基准测试套件中，与商业布局后门级功耗估计相比，PowerScope实现了5.88%的中位数和9%的平均绝对百分比误差，同时运行速度约快80倍。我们进一步证明了PowerScope的预测可可靠地用于硅前功耗侧信道泄漏评估这一下游任务。

## Abstract
Power estimation at sub-clock-cycle temporal resolutions is critical for tasks such as power delivery network (PDN) design, dynamic voltage droop analysis, and pre-silicon power side-channel security evaluation. Designers commonly rely on commercial post-layout gate-level power analysis tools for these tasks, but these flows are computationally expensive and scale poorly with design size and workload length. Machine learning (ML)-based power estimation frameworks have shown promise in accelerating power estimation, but prior efforts only address average power or per-cycle power estimation. We propose PowerScope, the first ML-based intra-cycle power estimation framework. PowerScope operates purely on RTL simulation traces at inference time, eliminating the need for post-layout gate-level simulation and power analysis per workload. Across a diverse benchmark suite, PowerScope achieves 5.88% median and 9% mean absolute percentage error compared to commercial post-layout gate-level power estimates while running ~80x faster. We further demonstrate that PowerScope's predictions can be reliably used for the downstream task of pre-silicon power side-channel leakage assessment.

- **现有 ML 方法的局限**：已有的机器学习功耗估计工作（如 SIMMANI、APOLLO、DEEP、ML-Power、GRANNITE、PRIMAL 等）仅能预测平均功耗或每周期功耗，无法提供周期内（亚时钟周期）分辨率的功耗曲线。将现有方法直接扩展到周期内场景存在诸多挑战（如功耗分布不平衡、特征选择开销大等）。
- **论文整体含义**：PowerScope 作为**首个基于 ML 的周期内功耗估计框架**，在推理阶段仅需 RTL 仿真轨迹即可获得布局后级别的周期内功耗，无需针对每个负载进行耗时后布局门级仿真和功耗分析，填补了该领域的空白。

## 2. 方法论：核心思想、关键技术细节与算法流程

PowerScope 分为一次性训练阶段和推理阶段，整体流程如图 2 所示。

### 核心思想
- 将时钟周期划分为均匀的 \(B\) 个时间箱（bin），每个箱跨度为采样周期 \(T_s = T_{clk}/B\)。
- 为每个 bin 训练一个独立的轻量级梯度提升树模型（LightGBM），输入特征来自 RTL 仿真轨迹，输出为该 bin 的功耗估计。
- 推理时完全绕过布局后门级仿真与功耗分析。

### 关键技术细节

1. **训练数据生成与分层子采样（Stratified Subsampling）**
   - 使用标准布局后流程（综合、P&R、后布局 GLS、PrimeTime PX）生成真实功耗标签。
   - 观察到某些 bin 的功耗分布呈双峰（bimodal）形态：一部分周期以泄漏功耗为主，另一部分周期具有明显动态开关功耗。若随机采样训练数据，会导致低功耗或高功耗区域覆盖不足，降低模型精度。
   - 解决方法：对每个 bin 按功耗值排序并划分为 \(K\) 个等总体分层（quantile-based stratification），从每层均匀采样，不足/过剩时按比例再分配，确保训练集覆盖完整功耗范围。

2. **STA 引导的特征选择（STA-Guided Feature Selection）**
   - 现有 MCP 正则化方法在周期内场景下需要对每个 bin 分别进行迭代超参数搜索，开销随 bin 数 \(B\) 线性增长。
   - PowerScope 利用静态时序分析（STA）获取每个门电路的开关窗口 \([t_{\min}(g), t_{\max}(g)]\)，若该窗口与某个 bin 的时间区间重叠，则认为该门电路可能在该 bin 内产生动态功耗，构成该 bin 的“潜在开关子集”（PSS）。
   - 对 PSS 中每个门电路，通过递归追踪其扇入寄存器，得到 bin 特定的寄存器集合。
   - 对每个选中的寄存器 \(R\) 和每个周期 \(c\)，构造两个二值特征：\(toggle(R,c)=R(c)\oplus R(c-1)\)（寄存器是否翻转）和 \(state(R,c)=R(c-1)\)（前一周期状态）。这些特征捕获了与输入相关的开关功耗成分。
   - 该算法只需一次遍历门级网表和 SDF 文件即可生成所有 bin 的特征集，复杂度与 \(B\) 无关。

3. **模型训练**
   - 每个 bin 训练一个独立的 LightGBM 模型。
   - 根据 bin 的功耗分布特性自适应调整树集成容量：
     - 高活跃度 bin：宽而浅的集成（叶子多、深度低、正则化轻）；
     - 功耗动态范围大的 bin：更深、正则化更强；
     - 泄漏主导的 bin：小型强正则化模型即可。

4. **推理**
   - 仅需 RTL 仿真（应用负载），提取 bin 特定特征，送入对应模型，得到完整周期内功耗轨迹。训练阶段所消耗的综合、布局布线等成本属于一次性开销。

## 6. 主要结论与发现

- **精度**：PowerScope 在 5 个设计上平均 MedAPE 为 **5.88%**，平均 MAPE 为 **9.05%**，与商业布局后功耗分析（PrimeTime PX）相当。
- **速度**：端到端推理速度提升约 **80 倍**，单个设计提升 15.2×（Fixed-point adder）至 248.4×（FMA）。
- **特征选择效率**：STA 引导的特征选择将每个 bin 的候选寄存器缩减至总 RTL 信号的 1%~20%（AES 最大 bin 约 5%），比 MCP 方法平均快 **12.5×**，且精度不下降。
- **分层子采样有效性**：对具有双峰功耗分布的 bin（如 FMA、AES 中的某些 bin），分层子采样比随机采样降低 MAPE 3~9 个百分点，同时提高 Spearman 相关系数。
- **采样周期影响**：采样周期越粗，误差通常越低，因为更宽的 bin 将功耗压缩得更平滑，但对组合逻辑设计（EPFL square）影响较小。
- **下游应用**：使用 PowerScope 预测的功耗轨迹进行 TVLA 测试，得到的 Welch's t-statistic 与基于 PrimeTime PX 的 ground truth 平均偏差仅 **11.7%**，可用于硅前功耗侧信道泄漏评估。

## 7. 优点

- **首次填补周期内 ML 功耗估计空白**：不同于以往只做平均或每周期功耗预测，PowerScope 直接输出亚时钟周期的功耗曲线，且推理时仅需要 RTL 仿真。
- **新颖的训练方法论**：
  - 识别并解决了周期内功耗分布的不均衡问题，提出分层子采样；
  - 提出 STA 引导的特征选择，利用时序窗口物理意义，低成本生成 bin 特定的功耗代理，避免 MCP 的逐 bin 迭代搜索。
- **模型设计贴合问题**：使用 LightGBM（树集成）在样本效率和捕捉非线性（如毛刺、逻辑重汇聚）之间取得平衡，且根据 bin 分布自适应调整模型容量。
- **实验验证充分**：涵盖多类型设计、消融实验、采样周期敏感性分析、下游 TVLA 应用验证。
- **实际意义强**：为 PDN 设计、电压跌落分析和硅前安全评估提供快速且准确的周期内功耗估计能力。

## 8. 不足与局限

- **验证设计规模有限**：最大设计为 4 万单元的 AES，未涉及大型处理器、GPU 或 SoC 级设计，扩展性需进一步验证。
- **未与所有现有 SOTA 对比**：与 GRANNITE、PRIMAL、APOLLO 等神经/图网络方法缺乏精度和成本对比（仅与 ML-Power 比较特征选择速度）。
- **训练成本未量化**：未报告合成、布局布线、训练数据生成和模型训练的具体时间/资源消耗，仅说明为一次性成本。
- **对不同工艺节点适应性未知**：实验仅在 GF 22nm 上完成，方法对其他工艺节点的可迁移性未讨论。
- **采样周期选择依赖经验**：对于不同设计，最优采样周期 \(T_s\) 可能需要根据设计特性调整，缺乏自动选择机制。
- **下游应用验证单一**：侧信道 TVLA 实验仅在一个 AES 设计上进行，未推广到其他加密或安全相关设计。
- **绝对精度仍有偏差**：某些设计（如 EPFL square、Radix-4 divider）MAPE 接近 15~18%，对绝对值要求高的场景（如 IR signoff）误差可能仍需改进。
- **推理速度评估不含训练阶段**：宣称的 80× 加速仅指推理阶段，且未包含综合和布局布线的一次性成本；若计入总流程，端到端收益需按使用频率评估。
