## 摘要
亚时钟周期时间分辨率下的功耗估计对于电源分配网络（PDN）设计、动态电压下降分析和预硅功耗侧信道安全评估等任务至关重要。设计人员通常依赖商业布局后门级功耗分析工具来完成这些任务，但这些流程计算成本高昂，且随设计规模和工作负载长度的扩展性较差。基于机器学习（ML）的功耗估计框架在加速功耗估计方面显示出潜力，但先前的工作仅涉及平均功耗或每周期功耗估计。我们提出了PowerScope，这是首个基于ML的周期内功耗估计框架。PowerScope在推理时仅基于RTL仿真轨迹运行，无需针对每个工作负载进行布局后门级仿真和功耗分析。在多样化的基准测试套件中，与商业布局后门级功耗估计相比，PowerScope实现了5.88%的中位数和9%的平均绝对百分比误差，同时运行速度提高约80倍。我们进一步证明，PowerScope的预测可可靠地用于预硅功耗侧信道泄漏评估这一下游任务。

## Abstract
Power estimation at sub-clock-cycle temporal resolutions is critical for tasks such as power delivery network (PDN) design, dynamic voltage droop analysis, and pre-silicon power side-channel security evaluation. Designers commonly rely on commercial post-layout gate-level power analysis tools for these tasks, but these flows are computationally expensive and scale poorly with design size and workload length. Machine learning (ML)-based power estimation frameworks have shown promise in accelerating power estimation, but prior efforts only address average power or per-cycle power estimation. We propose PowerScope, the first ML-based intra-cycle power estimation framework. PowerScope operates purely on RTL simulation traces at inference time, eliminating the need for post-layout gate-level simulation and power analysis per workload. Across a diverse benchmark suite, PowerScope achieves 5.88% median and 9% mean absolute percentage error compared to commercial post-layout gate-level power estimates while running ~80x faster. We further demonstrate that PowerScope's predictions can be reliably used for the downstream task of pre-silicon power side-channel leakage assessment.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题定义**：集成电路中有些关键任务（如电源分配网络 PDN 设计、动态电压跌落分析、时序收敛、预硅功耗侧信道安全评估）需要**亚时钟周期（intra-cycle）时间分辨率**的功耗估计，即在一个时钟周期内多个时间点（bins）分别给出功耗值。
- **现有方法的局限**：
  - 商业布局后门级流程（综合 → 布局布线 → 寄生提取 → SDF 反标 → 门级仿真 → PrimeTime PX 功耗分析）精度高、时间粒度细，但计算开销极大，随设计规模和工作负载长度扩展性差。
  - 现有基于 ML 的功耗估计工作（如 SIMMANI、APOLLO、DEEP、ML-Power、GRANNITE、PRIMAL）只覆盖平均功耗或逐周期功耗，**均未解决周期内（intra-cycle）功耗估计**问题。
- **核心意义**：PowerScope 是**首个**基于 ML 的周期内功耗估计框架，在推理阶段仅需 RTL 仿真轨迹，即可逼近布局后门级功耗分析的精度，同时大幅加速。

### 2. 方法论：核心思想、关键技术细节与流程

PowerScope 采用两阶段流程：

- **训练阶段（一次性成本）**：
  1. 用 RTL 设计和一组微基准（micro-benchmarks）驱动两条并行流水线：
     - 流水线 A：RTL 仿真 → 特征提取，生成训练输入特征；
     - 流水线 B：逻辑综合 → 布局布线 → 布局后门级仿真 → PrimeTime PX 功耗分析，生成 ground-truth 周期内功耗标签。
  2. **分层子采样（Stratified Subsampling）**：对每个 bin，按功耗值排序并划分为 K 个等人口分层（strata），从每层均匀采样，保证训练集覆盖全功耗范围。动机：周期内某些 bin 的功耗呈**双峰分布**（如低功耗泄漏模式 + 高功耗活动模式），朴素随机采样会欠采样某一模式，导致精度下降。
  3. **STA 引导的特征选择**（Algorithm 1）：
     - 利用门级网表和 SDF（标准延迟格式）文件，计算每个门的到达时间窗口 [t_min(g), t_max(g)]；
     - 若该窗口与某个 bin b 的时间窗口重叠，则门 g 属于 bin b 的"潜在切换子集"（PSS）；
     - 回溯 PSS 中每个门的传递扇入至寄存器，得到 bin 特有的寄存器集合；
     - 对每个选中的寄存器，每个周期提取两个二元特征：**toggle 指示**（R(c) ⊕ R(c−1)）和**前一周期状态**（R(c−1)）；
     - 相比现有 MCP（极小极大凹惩罚）正则化特征选择（需对每个 bin 做独立迭代超参搜索），STA 方法**单次遍历**即可得到所有 bin 的特征子集，且不依赖 bin 数量 B。
  4. **模型训练**：每个 bin 训练一个独立的 **LightGBM**（梯度提升树）模型。动机：树模型在样本效率上优于深度学习，又能捕捉门级功耗中的非线性效应（如毛刺、路径延迟不平衡导致的逻辑再汇聚）。按 bin 的功耗分布特性做网格搜索微调超参：高活动 bin 用宽而浅的集成，宽动态范围 bin 用更深、正则化更强的集成，泄漏主导 bin 用小容量强正则化集成。

- **推理阶段（仅 RTL）**：
  - 给定应用工作负载 → RTL 仿真 → 按训练阶段确定的 bin 特定特征集提取特征 → 喂给各 bin 的 LightGBM 模型 → 输出周期内功耗轨迹。
  - 完全绕过布局后门级仿真与功耗分析。

### 6. 主要结论与发现

- PowerScope 是首个 RTL-only 推理的 ML 周期内功耗估计框架，中位误差（MedAPE）**5.88%**、平均误差（MAPE）**9.05%**，端到端加速 **~80 倍**（范围 15.2×～248.4×）。
- STA 引导特征选择将每个 bin 的代理数量压缩到全设计的 **1%～20%**（最大设计 AES 中最高仅 5.0%），且 bin 越晚、代理越少（如 AES 从 b0 的 2,303 个降至 b9 的 51 个）；特征选择成本比 MCP 方法低 **12.5×**。
- 分层子采样对**双峰分布 bin 占比高**的设计（FMA、AES）显著改善精度（FMA 的 MAPE 从 16.36% 降至 13.20%），对单峰主导的设计（加法器、EPFL square、Radix-4）影响不大。
- 采样周期变粗通常降低误差（因为 bin 内功率被平均、动态范围压缩），但对开关活动几乎覆盖整个周期的设计（EPFL square）影响有限。
- PowerScope 的周期内功耗预测可直接用于 TVLA 侧信道评估，逐 bin Welch's t 统计量相对 ground-truth 平均偏差仅 **11.7%**。

### 7. 优点

- **问题新颖**：首次系统定义并解决 ML 周期的内功耗估计问题，填补了现有 ML 功耗估计工作（平均/逐周期）与商业周期内工具之间的空白。
- **特征选择高效且可解释**：利用 STA 时序窗口信息，将时序物理分析与特征子集确定结合起来，单次遍历即可生成所有 bin 的代理集，避免 MCP 在周期内场景下的逐 bin 迭代搜索，物理语义清晰。
- **训练策略针对性强**：识别到周期内功耗分布的双峰/偏斜问题，提出基于分位数分层的子采样方案，对症下药。
- **模型选择合理**：采用 LightGBM，兼顾非线性建模能力与训练/推理效率，并针对不同 bin 的分布特性做容量适配。
- **验证视角全面**：同时报告绝对误差与秩相关，并区分两者对下游任务的不同价值；额外做 TVLA 下游验证，展示了实际应用价值。

### 8. 不足与局限

- **实验覆盖有限**：仅 5 个设计，规模最大约 4 万单元；未验证在更大规模 SoC（如完整处理器核、多时钟域设计）或更复杂功耗场景（如时钟门控、动态电压频率调节）下的表现。未能与深度学习类基线（GRANNITE、PRIMAL）直接比较。
- **特征选择的简化假设**：STA 窗口重叠准则只考虑门的到达时间与 bin 的时序窗口，未显式处理毛刺（glitch）传播、路径延迟失衡、逻辑再汇聚等非线性动态功耗来源（虽然文中指出 LightGBM 可以隐式学习这些效应，但特征层面没有显式编码），也没有考虑静态功耗/泄漏功耗随温度电压的变化。
- **训练成本仍然不低**：虽然推理很快，但训练阶段仍需完整的综合、布局布线、布局后门级仿真与功耗分析；论文未量化单次训练所需的时间和资源；也未说明训练集规模、超参搜索代价。

- **下游验证深度有限**：仅做了单设计（AES）的 TVLA 检测；未评估在 PDN 设计/电压跌落分析中的实际误差传播效应。
